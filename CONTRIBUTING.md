# Contributing

Thank you for looking. It means something that you took the time, and a good
bug report is worth a great deal.

## The honest shape of this project

Nextup is written and maintained by one person at Lightmorphic. Code changes
from outside are not merged. That is not a judgement on anyone's work, it is
simply how the project is set up: everything here is read, understood and
carried by one person, and that only works while there is one hand on it.

So please do not spend an evening on a pull request expecting it to land. If
you want to change how Nextup works for you, fork it. The GPL gives you that
right and you are welcome to it.

## What helps most

A description of the problem.

- What you did
- What you expected to happen
- What actually happened
- The version number, which is in the corner of any page in the app
- How you are running it: the image tag, your compose file with any secrets
  taken out, and the operating system

Open it as an issue on this repository, or email
<complaints@lightmorphic.com> if you would rather not have an account.

Ideas and feature requests are welcome in the same place. They may not be
taken up, and a short no is not a brush-off, it is one person keeping the
project small enough to stay good.

## Security problems go privately

Please do not open a public issue for a vulnerability.
[SECURITY.md](./SECURITY.md) has the private route.

## Translations and artwork

Nextup is English only at the moment and the interface strings are not
extracted, so there is nothing useful to translate yet.

Show and film artwork comes from TheTVDB and is not ours to relicense. The
Manrope font is under the SIL Open Font Licence, included with the font files.
